 # 私人规划执行助理 Web 前端重构（PRD）
 
 ## 1. 背景与目标
 当前项目 UI 使用 Streamlit（Python）实现，视觉效果与交互体验已达到预期，但技术栈不符合“前端应使用 JavaScript/HTML/CSS 实现”的产品诉求。
 
 **目标**：在不改变现有产品功能与交互逻辑（聊天、方案卡片、SSE 流式输出、决策流程可见、定位授权与位置徽标等）的前提下，将 UI 迁移为纯 Web 前端（JavaScript + HTML + CSS），并保持现有“极光背景·流光边框·3D 变换·粒子/光效”的设计灵感与动效逻辑。
 
 ## 2. 范围
 ### 2.1 必须包含（MUST）
 - 与后端 FastAPI 的现有接口兼容：
   - `POST /init`
   - `POST /chat/stream`（SSE）
   - `GET /health`
 - 还原并保持现有 UI 关键体验：
   - 顶部 Hero/品牌区（标题、副标题、背景氛围）
   - 聊天消息流（用户/助手气泡、头像）
   - 方案卡片解析与展示（叠层卡片、选择按钮、圆点导航）
   - “决策流程可见性”：点线流程图 + 当前阶段状态条（SSE pipeline 事件驱动）
   - “彩色旋转等待框 + 彩色线条进度条”在长时间决策时可见（status/delta 驱动）
   - 定位授权（允许/跳过）+ 浏览器定位（geolocation）+ 右上角位置徽标显示
 - 保持现有产品行为：
   - session_id 生成与复用
   - 将定位（lat/lng/label）随请求带入后端
   - 不泄露敏感信息（邮箱/密钥等）
 
 ### 2.2 非目标（WON'T）
 - 不改后端业务逻辑（规划、去重、执行等）
 - 不引入登录/账号体系
 - 不实现移动端专属设计（默认桌面优先，可自适应）
 
 ## 3. 用户故事
 1) 作为用户，我输入需求后希望看到“正在做事”的可视化流程与等待动画，减少等待焦虑。  
 2) 作为用户，我希望方案以卡片形式呈现，且可以一键选择某个方案继续执行。  
 3) 作为用户，我希望系统能请求定位授权，并在右上角持续显示当前检索中心位置。  
 
 ## 4. 交互与信息架构
 - 页面结构（从上到下）：
   1) 顶部背景/品牌 Hero（动效背景层）
   2) 右上角定位区域：
      - 授权按钮（未决定时显示“启用定位/跳过”）
      - 已授权时显示定位图标按钮（重新获取/刷新定位，可选）
      - 位置徽标（label 省略显示）
   3) 对话区：
      - 消息列表
      - 处理中：点线流程 + 等待动画卡片（同时显示）
      - 输入框（带发送按钮）
   4) 侧边栏（可折叠）：
      - 服务在线状态
      - 会话信息
      - 重置会话
 
 ## 5. 数据与事件协议（前端与后端）
 - `POST /chat/stream` 返回 SSE，事件类型（JSON）：
   - `{type:"session", session_id}`
   - `{type:"pipeline_config", stages:[{id,label,active_msg,done_msg,icon}] }`
   - `{type:"pipeline_stage", stage_id, status:"pending|running|done|error", msg?}`
   - `{type:"status", content, is_done:false}`（可选）
   - `{type:"delta", content, is_done:false}`（流式文本）
   - `{type:"done"}`
 
 ## 6. 视觉与动效要求
 - 继承现有 Inspire UI 设计灵感：
   - 暗色基底 + 极光/流光渐变 + 玻璃拟态层
   - 关键组件具备“流光边框/柔光投影”
   - 进入与交互动画（hover/press/appear）
 - 动效优先级：
   1) 背景氛围（低性能开销）
   2) 流程点线（running 节点脉冲 + 连线闪烁）
   3) 等待卡片（旋转环 + 彩色进度条）
 
 ## 7. 验收标准（Definition of Done）
 - 前端完全不依赖 Streamlit；可通过浏览器访问 Web 页面完成同等功能
 - 不修改后端接口即可正常聊天、生成方案卡片、选择方案继续执行
 - 处理过程中同时显示：点线流程 + 等待动画
 - 定位授权、定位获取、右上角位置徽标可用
 - 视觉风格与现有 Streamlit 版本保持一致（同一设计语言与特效逻辑）
